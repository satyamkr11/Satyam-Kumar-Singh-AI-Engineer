# Satyam Kumar Singh - AI/ML Portfolio V2

A modern, responsive, recruiter-friendly portfolio website for Satyam Kumar Singh, a B.Tech CSE AIML student and aspiring AI/ML Engineer.

## Highlights

- Clean personal brand and hero section
- Skills grouped by programming, AI/data, cloud, and professional strengths
- Project cards with GitHub and certificate links
- Education and career goal section
- Certifications section with local PDF/image assets
- Sports leadership section
- Contact links for email, LinkedIn, and GitHub
- Mobile responsive navigation

## Tech Stack

- HTML5

- JavaScript
- Static deployment ready for GitHub Pages, Netlify, Vercel, or AWS EC2 Apache2
